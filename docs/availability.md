# Availability and access paths

Last reviewed: October 27, 2026.

Start with the [official supported locations](https://support.claude.com/en/articles/8461763-where-can-i-access-claude). Check the live list for your actual situation rather than relying on a copied country table or an IP lookup. For travel, relocation, or an apparent classification error, ask support how the current rules apply before purchasing.

| Situation | Next step |
| --- | --- |
| You are eligible and need individual coding access | Review Pro/Max and the macOS quickstart |
| Your employer provides access | Ask the workspace administrator about your seat and billing |
| You need programmatic API use | Review Console or an officially supported cloud provider's own terms, regions, and charges |
| You are outside supported availability | Seek clarification from support; monitor official expansion announcements |
| Your eligible account appears misclassified | Collect a private, minimal problem description and request review |

The [official setup documentation](https://code.claude.com/docs/en/setup) describes subscription, Console, and supported cloud-provider authentication. These routes have different billing and eligibility requirements. A cloud provider is not a guaranteed alternative in an unsupported region.

While waiting for availability, keep developing with tools available to you, including locally runnable open-weight models suitable for your hardware and license requirements. They do not provide Claude subscriptions or equivalent model behavior. Keep project instructions, source code, and tests portable so changing tools does not strand your work.

Our advocacy priorities are broader regional availability, affordable access, clear eligibility explanations, useful appeal mechanisms, and protection against paying for access that cannot be used. Contributions documenting barriers should omit personal information and distinguish observed failures from inferred causes.
